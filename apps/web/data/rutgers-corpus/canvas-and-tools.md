# Canvas and student tools

## Canvas
- Rutgers Canvas: https://canvas.rutgers.edu/
- Login uses NetID; no third-party agent should ask for passwords.
- Syllabus, assignments, and announcements live per course site.

## Calendar
- Export Canvas calendar or subscribe in Google/Apple Calendar from Canvas settings.
- Combine with SOC-based schedule in Course Schedule Planner.

## Email & NetID
- Official communications use Rutgers email. NetID manages access to Canvas, Wi-Fi, and library.

## Where agents should stop
- Cannot submit assignments, post on Canvas, or access grades without the student logged in.
